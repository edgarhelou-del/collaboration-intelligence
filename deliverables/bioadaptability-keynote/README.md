# Bioadaptability — Keynote Package

Deliverables for the "Bioadaptability" keynote (persona / equipo / organización,
adaptación en un futuro incierto). ~25-30 minute international keynote.

## Files

- **`Bioadaptability_Keynote.pptx`** — 30-slide deck. One dominant visual per
  slide, minimal on-screen text, full speaker notes on every slide.
- **`Bioadaptability_Narrative.docx`** — Tesis, historia hilo conductor,
  arquitectura de 9 actos, momentos WOW, paradojas, historias, preguntas,
  frases memorables, cierre, y el "test definitivo".
- **`Bioadaptability_Research.xlsx`** — 25-idea research database scored on
  Intellectual Power / Evidence / Corporate Relevance / Originality / Story /
  Visual / Emotional potential, each with a real source and URL.
- **`Bioadaptability_Image_Sources.xlsx`** — Slide-by-slide image sourcing:
  real Wikimedia Commons / NASA Earth Observatory / NIH BioArt / Unsplash
  assets identified for every slide, with author, license and attribution
  text, plus a licensing-notes sheet.

## Important: about the images currently in the .pptx

The sandboxed build environment used to assemble this package could not
reach external image hosts (Wikimedia Commons, NASA, Unsplash — every
outbound host tested returned a policy-level 403 from the sandbox's egress
proxy). So the deck currently ships with **generated placeholder artwork**
(abstract gradient/line/particle compositions matching each slide's color
direction and metaphor) rather than the real photographs.

Every real photograph has already been identified, license-checked and
written into `Bioadaptability_Image_Sources.xlsx` — author, exact URL,
license, and ready-to-use attribution text. To finish the deck:

1. Open `Bioadaptability_Image_Sources.xlsx`.
2. For each slide, download the real image from the URL given (most are
   direct Wikimedia Commons file pages, NASA Earth Observatory pages, or
   Unsplash photos — all confirmed public domain or Creative Commons /
   Unsplash-licensed).
3. In `Bioadaptability_Keynote.pptx`, replace that slide's background image
   with the downloaded photo (same full-bleed placement).
4. A few rows are marked "Verify Before Final Use" — these point to a
   Wikimedia Commons category or an Unsplash search rather than one locked
   file; pick one specific file from the link and copy its exact author/
   license into the sheet before using it publicly.

No other content — thesis, script, speaker notes, research, stories — is
placeholder. Only the slide backgrounds need this one swap.
